# Roadmap

## Current: GUM School training lane

- authored curriculum for all ten planned schools and twelve capability grades;
- machine-readable foundational sequence for Object Laboratory, Causal
  Workshop, and Changing Maze;
- strict curriculum, lesson, examination, and world-admission schemas;
- semantic validation for leakage, seed separation, supported identifiers, and
  feasible budgets; and
- adversarial negative fixtures.
- content-addressed promoted and candidate snapshots;
- strict evaluation records and computed seven-gate decisions;
- quarantine, atomic pointer promotion, and interruption recovery; and
- append-only decision and isolated-source transfer-matrix reporting.
- source-reviewed Object Laboratory, Causal Workshop, and Changing Maze
  adapters with distinct mechanisms;
- strict data-only world packages and a closed six-generator registry; and
- deterministic admission evidence covering horizons, replay, leakage,
  inspection, and random/scripted controls.
- a strict persistent learner whose parameters are shared across seeds;
- on-demand uncertainty-triggered replication capped at four helpers;
- separate helper episode streams, value communication, and evaluation voting;
- bounded candidate training and matched-fresh development evaluation;
- deterministic evaluation replay and source/artifact hashing; and
- a real engine rehearsal that quarantined the candidate and preserved the
  promoted snapshot.

The first-lesson swarm scored 32/32, compared with 0/32 for a matched fresh
swarm. Under the same 16-episode budget, a deterministic single-replica
ablation scored 25/32 and missed the development threshold. The learner is now
development-ready for the first lesson, but not officially passed. The next
milestone is an immutable first-lesson freeze and independent withheld
evaluation, alongside development work on the later lessons.

## Now: frozen research snapshot

- persistent concepts and skills;
- distinct-skill composition;
- real JSONL workflow transfer;
- multi-seed narrow meta-learning;
- auditable protocols and evidence packages.

## External validity

1. Give a frozen commit to an independent evaluator.
2. Accept task packages created after the freeze.
3. Run at least thirty meta-seeds.
4. Add established search, planning, RL, and meta-learning baselines.
5. Publish failures alongside successes.

## Then: less engineered perception

- learn attention and object boundaries from ordinary scenes;
- remove the custom changed-pixel summary;
- test occlusion, moving cameras, clutter, sound, and delayed effects;
- connect language to learned concepts rather than fixed command templates.

## Then: tool discovery

- choose among unfamiliar tools based on observed effects;
- synthesize safe compositions of tools;
- test whether new tools reduce learning cost in later domains;
- retain rollback, sandbox, and verification boundaries.

## Long-term criterion

The same frozen mind should enter an unfamiliar game, ordinary desktop application, data workflow, and simulated workshop; learn each; explain what it learned; retain all four; then learn a fifth unrelated environment substantially faster because its learning machinery improved.
