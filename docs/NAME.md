# What should GUM stand for?

## Recommendation: Growing Understanding Machine

This is the best current name because every word earns its place:

- **Growing:** its concepts, skills, domain memories, and acquisition strategy change with experience.
- **Understanding:** it builds compact causal and procedural representations useful for prediction and action. This is an operational research meaning, not a claim of human consciousness.
- **Machine:** concrete, modest, and implementation-oriented.

It also gives us a natural sentence: “GUM is a machine whose understanding grows through experience.”

## Other good expansions

| Name | Strength | Problem |
|---|---|---|
| Grounded Understanding Machine | Emphasizes perception and action | Says less about continual growth |
| Generalist Utility Mind | Memorable and practical | “Mind” invites stronger claims |
| Growing Unified Memory | Accurate for accumulation | Undersells reasoning and action |
| Grounded Universal Model | Sounds technical | “Universal” currently overclaims |
| General Understanding Machine | Bold and clear | Claims generality before it is demonstrated |

## Recommendation on branding

Use **Growing Understanding Machine** in the repository and paper. Keep “generally understanding mind” as the long-term aspiration, not the present acronym expansion.
